# Repository audit — 2026-11-07

Status: local repository audit completed, with verified corrections and explicit
remaining limitations. This is not a release qualification or a P07/P08/P09
completion record.

## Scope and preservation

Eight specialists and the lead reviewed Go service code, subprocess/HTTP/audio
boundaries, configuration and models, Python security/release tooling, acceptance
helpers, Docker/Compose, Helm/GitHub Actions, and contributor/operator documentation.
The public Resident V1 contracts, separate ordinal-paired components, native source,
GPU ownership, selected toolchains and existing user changes were preserved.
The user explicitly approved the Echo security patch from v5.4.0 to v5.4.1.
The audit also applies exact Ubuntu runtime security updates after fresh image
findings: apt/libapt, Brotli, PCRE2/zlib and the older CUDA image's affected OS
packages, with zero-retry operation for unpatched APT.
A superseded Ubuntu CA package pin is refreshed to its published patch version.
Base-image digests, CUDA, FFmpeg source and the native inference revision remain
unchanged.

The starting worktree already contained extensive changes, including short-WAV
mitigation, Docker cache work and development acceptance helpers. Those changes
were not reset or reattributed to this audit. No commit, push, publication,
deployment, cluster mutation or real GPU workload is part of this audit.
Workflow-managed state was not edited; its required MCP is unavailable, so managed
specification freshness and formal packet transitions are not claimed.

## Findings and corrections

Severity describes this project's observed exposure, not a new CVSS score.

| Severity | Finding | Correction and evidence |
| --- | --- | --- |
| High | Early HTTP replies could wait on an unread request body; a non-reading response client could retain a staging slot. | Bound response writes and stop draining unneeded bodies at the HTTP boundary. Wire-level regressions cover early errors/probes and stalled output. |
| High | Registry credentials could follow redirects through Python's default HTTP handling. | Send Basic/Bearer credentials only on their original requests; redirected reads do not inherit authentication. |
| High | Incomplete scanner output or malformed finding fields could be treated as clean. | Reject missing coverage and invalid finding fields; do not let suppression-like fields hide vulnerability findings. |
| High | Echo v5.4.0 caused four symbol-level findings in the fresh Go vulnerability database. | Update only Echo to v5.4.1, verify module sums, remove obsolete Echo exceptions, and repeat vulnerability/behavior checks. This does not change published images. |
| High | A second backend health observation could switch the dispatched generation without updating its application owner, allowing premature cleanup acknowledgement. | Bind the internal inference input to the observed generation and reject drift before POST; preserve the existing public/private HTTP schemas. |
| High | An OCI index could include an uninspected additional runtime manifest. | Accept only the selected Linux amd64 runtime and its verified attestations; reject unchecked platform descriptors. |
| High | New release assets were not read back before marking a stable release latest. | Read back and compare both existing and newly uploaded bytes, then promote latest only after all comparisons succeed. |
| High | Fresh image scans found vulnerable apt/libapt and Brotli packages. | Install exact fixed Ubuntu packages, bootstrap old APT with zero retries in builder and runtime stages, then rebuild and rescan. Official Brotli CVSS severity is critical even though Ubuntu/Trivy prioritize these package findings as HIGH. |
| Medium | Valid very small temperatures expanded beyond the private scalar limit; native decimal float parsing could underflow. | Compact Go-to-Go serialization and exact native float32 serialization preserve accepted values, including representable subnormals. |
| Medium | Unused compiled FFmpeg video decoders contained newly reviewed vulnerabilities. | Exclude the affected decoder entries, including shared Huffyuv variants, and inspect the resulting packaged registry; preserve all supported audio families with real decoder controls. |
| Medium/Low | The older CUDA base inherited many fixable Ubuntu OS package findings beyond the API image's PCRE2/zlib cases. | Pin the affected runtime packages to verified signed Noble security/update versions within their existing upstream series. Preserve CUDA/native/compiler versions; do not perform an unpinned blanket upgrade. |
| Medium | Scanner subprocess descendants could survive timeout or successful parent exit. | Own and retire a process group through a shared private runner; keep raw scanner output private. |
| Medium | A completed FIFO request could still occupy the sole slot when its caller submitted the next request. | Retire active ownership after resource cleanup but before publishing completion; repeated sequential requests with zero waiting capacity reproduce the old race. |
| Medium | Adding cleanup slack could overflow a valid large timeout; typed settings admitted values the loader rejected. | Add deadlines without overflowing durations and align typed validation with existing loader bounds. |
| Medium | Supported media extensions and mixed-case filenames could enter Docker build context. | Extend media exclusions, preserving explicit public fixture exceptions. A real BuildKit export regression observes the artifact rather than checking ignore-file text. |
| Medium | Interrupted chart retry could fail against an unset digest, or treat an authenticated manifest as publicly verified. | Recover an initially unknown digest while retaining immutable collision checks; require matching anonymous manifest and archive readback. |
| Medium | Acceptance helpers could accept malformed public errors, leak command descendants, or report an incomplete observer as successful. | Share bounded reply validation and process ownership; distinguish explicit cancellation from deadline/early exit, join output readers, and test limits using CPU-only executable fixtures. |
| Medium | Scratch observation scanned unrelated host processes and could miss an explicitly owned child absent from that global snapshot. | Traverse the selected owner's children across all threads, bracket PID/start identities, and fail closed on missing selected observations without increasing timeout budgets. |
| Low | Prepared-model and non-root container fixtures assumed a particular umask. | Verify preservation of the actual original prepared-file mode; explicitly set only synthetic fixture permissions required by runtime UID 10001. Restrictive umask and production permissions remain unchanged. |
| Low | Repeated race-enabled fake CLI dispatch accumulated the detector's default one-second exit sleep, exhausting the full-suite budget. | Remove only that sleep in the child fixture environment. Preserve instrumentation and inherited options, prove detection with a joined child race, and leave parent/product environments and service deadlines unchanged. |

Changes prefer existing libraries and the standard library. No generic framework,
DI container, new service dependency, repository-file checker or speculative native
model parser was introduced.

## Remaining boundaries

A local source audit cannot certify the unchanged native implementation, a live
cluster, GPU memory reclamation, continuous old/new GPU non-overlap or published
artifact safety. See the [security review](<security-audit-2026-11-07.md>) for native
advisory applicability and remaining evidence gaps. Model checksum verification
establishes artifact identity, not safety of a malicious model; use trusted models.

**The security gate is not qualified.** Pinned Trivy can discard inline-suppressed
configuration findings before JSON output. Its real-tool regression remains an
expected failure, and inspection of the newer official 0.76.2 source/CLI did not
establish a compatible fix. Native/CUDA review freshness and complete artifact
coverage also remain unresolved. Forty GPU/target acceptance skip events were
intentional in the CPU-only run; no passing CPU test substitutes for them.

The canonical Compose stack mounts cache at `/models`. Custom paths require an
explicit volume/permission override; no privileged initializer was introduced.
Full hosted CI/security qualification and real GPU/cluster checks remain distinct
from local tests. Existing accepted limitations and expired/failed historical
checks were not relabeled as passes.
