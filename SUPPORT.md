# Support

Use [GitHub issues](https://github.com/swimmwatch/openwhispr-whisper-server/issues)
for ordinary questions, bug reports and feature proposals. This is a community
project; there is no guaranteed response time or commercial support commitment.

Include the source revision, component/tool versions, sanitized configuration,
hardware/runtime details and a minimal synthetic reproduction. Never include
credentials, private audio or transcripts. The project is currently in bootstrap
development; runnable setup instructions and the final README are pending.

Report suspected vulnerabilities through [SECURITY.md](SECURITY.md). Report
conduct concerns through the private contact in [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).
