# Support

Use [GitHub issues](https://github.com/swimmwatch/openwhispr-whisper-server/issues)
for ordinary questions, bug reports and feature proposals. This is a community
project; there is no guaranteed response time or commercial support commitment.

Start with the [README](<README.md>), [operator guide](<docs/operations.md>) and
[chart guide](<charts/whisper-server/README.md>). Include the source revision or
release plus exact image/chart identities, component/tool versions, sanitized
configuration, GPU/driver/runtime details and a minimal synthetic reproduction.
Report expected and actual HTTP status/error codes and readiness behavior.
Never include credentials, private cluster identities, audio or transcripts.

The [recorded release limitations](<docs/verification/release-1.0.0-notes.md>) remain
important: publication, a successful transcript or a closed packet with accepted
limitations is not full GPU, memory or current security qualification.

Report suspected vulnerabilities through [SECURITY.md](SECURITY.md). Report
conduct concerns through the private contact in [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).
